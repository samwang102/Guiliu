# 归流（Guiliu）

归流是一款面向 macOS 的本地文件整理工具。它把下载目录、桌面和用户选择的应用文件目录汇入统一待归档队列，通过快捷面板完成分类、重命名、预览、搜索和可恢复删除。

## 主要能力

- 监视用户授权的目录，并在发现新文件时显示快捷归档面板。
- 下载文件以移动方式归档；其他应用管理的文件可保留原位并建立引用。
- 使用有限、通用的物理分类，避免自动创建越来越多的目录。
- 支持不改变磁盘结构的多维分类和智能标签。
- 提供文件名搜索、全文搜索、结构化筛选和当前分类内搜索。
- 支持 Quick Look 预览、重命名、重新分类，以及通过 macOS 废纸篓删除和恢复。
- 可选连接本机 Ollama；AI 分析只在用户主动触发时运行。

所有索引、标签、历史和 AI 结果均保存在本机。项目不包含遥测或云端上传逻辑。

## 系统要求

- macOS 14 或更高版本
- Swift 6.2 或更高版本
- 可选：本机运行的 [Ollama](https://ollama.com/)

## 构建与测试

```bash
swift test
swift run Guiliu
```

首次启动时，macOS 会按实际启用的监视目录请求访问权限。测试自定义目录时可使用：

```bash
GUILIU_MONITOR_PATH=/path/to/inbox \
GUILIU_LIBRARY_PATH=/path/to/library \
swift run Guiliu
```

## 隐私与安全

- 文件操作限定在用户授权的来源目录和文件库中。
- 路由、重命名、删除与恢复会校验文件身份，并避免覆盖已有文件。
- 符号链接和越界路径不作为可写目标处理。
- Ollama 请求只发送到本机回环地址。
- 提交 Issue 或 Pull Request 时，请只使用明确虚构的样例，不要上传真实文档、聊天附件、用户路径或个人分类体系。

安全问题请遵循 [SECURITY.md](SECURITY.md) 私下报告。贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。
